Aroma Luxury Store 🌸

An interactive e-commerce web application designed for a luxury perfume boutique, offering oriental oud oils, French perfumes, and royal bakhoor collections.

 🌟 Features
- **Royal Navigation:** Multi-category navigation including Men, Women, Oud & Incense, and Blog pages.
- **Trending Scents:** Showcases popular products with pricing and discount badges.
- **Customer Reviews:** Dedicated testimonial section featuring verified buyers.
- **Responsive E-Commerce Layout:** Clean grid and flexbox structure for an enhanced user shopping experience.

 🛠️ Tech Stack
- HTML & HTML5
- CSS  & CSS3
